# Maze Solving Robot 🚗🧩

An autonomous maze-solving robot simulation designed to navigate through complex wall-based environments using intelligent navigation and obstacle avoidance techniques.

---

## 📌 Overview

This project demonstrates a mobile robot capable of navigating through a maze environment while avoiding walls and finding a valid path autonomously.

The simulation focuses on:
- Autonomous navigation
- Wall-following behavior
- Obstacle detection
- Path decision making
- Maze exploration

---

## ✨ Features

- 🤖 Autonomous robot movement
- 🧱 Wall and obstacle detection
- 🧭 Maze navigation
- ⚡ Real-time simulation
- 🛣️ Corridor traversal and turning logic
- 🎯 Intelligent movement decisions

---

## 🛠️ Technologies Used

- Webots Simulator
- Python / C
- Differential Drive Robot
- Distance Sensors
- Autonomous Navigation Algorithms

## 🚀 How It Works

1. The robot scans nearby walls using distance sensors.
2. Movement decisions are made based on obstacle availability.
3. The robot follows open paths while avoiding collisions.
4. Navigation continues until the maze is explored successfully.
