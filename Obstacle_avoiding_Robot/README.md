# Obstacle Avoidance Robot using e-puck

## 📌 Overview
This project demonstrates an autonomous obstacle avoidance robot using the e-puck robot in the Webots simulation environment.  
The robot uses proximity sensors to detect nearby obstacles and automatically changes direction to avoid collisions while navigating safely.

---

## 🚀 Features
- Real-time obstacle detection
- Autonomous robot navigation
- Sensor-based movement control
- Collision avoidance system
- Webots simulation using e-puck robot

---

## 🛠️ Technologies Used
- Webots Simulator
- Python
- e-puck Robot
- Proximity Sensors

---

## ⚙️ How It Works
The robot continuously monitors data from its proximity sensors.  
When an obstacle is detected within a predefined range, the controller adjusts the wheel velocities to change direction and avoid collision.
