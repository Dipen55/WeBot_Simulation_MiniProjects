# Webots Mini Projects Collection

## 📌 Overview
This repository contains a collection of robotics mini projects developed using the Webots simulation platform.  
The projects focus on autonomous robotics, sensor integration, navigation algorithms, and robotic control systems using the e-puck robot.

These projects are designed for learning, experimentation, and robotics research.

---

# 🚀 Projects Included

## 1️⃣ Obstacle Avoidance Robot
An autonomous robot that detects obstacles using proximity sensors and changes direction automatically to avoid collisions.

### Features
- Real-time obstacle detection
- Autonomous navigation
- Collision avoidance
- Sensor-based control

---

## 2️⃣ Line Following Robot
A robot capable of following a predefined path using line detection sensors and control logic.

### Features
- Line tracking
- Path following
- Sensor calibration
- Autonomous movement

---

## 3️⃣ Wall Following Robot
A robot designed to maintain a constant distance from walls while navigating an environment.

### Features
- Distance monitoring
- Stable navigation
- Proximity sensor integration

---

## 🛠️ Technologies Used

## ▶️ Getting Started

### 1️⃣ Install Webots
Download and install Webots from the official website.

### 2️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/Webots-Mini-Projects.git
```

### 3️⃣ Open Any Project
Navigate to the desired project folder and open the `.wbt` world file in Webots.

### 4️⃣ Run the Simulation
Click the **Run** button inside Webots to start the simulation.
